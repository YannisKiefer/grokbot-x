# Image prompts (ready to paste into ChatGPT)

Every prompt below stands alone: copy one block, paste it, and generate. Shared rules, already written into each prompt:

- Palette: paper `#F7F7F5`, ink `#000000`, sticker yellow `#FFD400`, sticker green `#19D27C`, sticker blue `#2B3BFF`, glitch red `#FF2D55`, glitch cyan `#00D8F0`.
- Type feel: heavy grotesk like Inter Tight ExtraBold, tight letter spacing, sentence case.
- Never draw the X or Twitter bird, the xAI or Grok marks, real people, or real X screenshots.
- Image models garble long text. Where a prompt needs exact words, render the text yourself afterwards and use the image for layout only.
- When an image needs a logo, leave the stated empty space. Drop in a real logo file later; never let the model invent one.
