# X human cadence

## Hard rules

1. **7 days/week including weekends.** Humans post Saturdays and Sundays.
2. Max **1 original post per hour**. Never burst. Never catch up missed hours
   in one dump.
3. **Anti-bot timing:** never publish on the same clock minute every hour.
   Cron wake is not publish time. Add random within-hour jitter (0-35 min)
   before shipping. Prefer irregular cron minutes (not :00). Uneven reply gaps.
4. Full feed behavior, not post-only: **scroll, like, bookmark/save, reply**,
   then post.
5. Engage what resonates with YOUR_PRODUCT and your ICP niche. Skip random
   off-niche virality. Viral signal filter still applies. See
   `skillopt/best_skill.md`.
6. Replies in small batches with gaps. Never rapid-fire 10+.
7. Daytime denser, evenings lighter, no overnight spam dumps.
8. Content disclosure **Made with AI** OFF. Never generate AI images unless
   the operator asked.
9. If a live post shows the AI label, delete it and fix the publish path.
   See `docs/PUBLISH.md`.

## Session shape (think phone user)

- Wake (irregular) -> wait jitter
- Open feed -> scroll
- Like / save a handful that fit
- 0-2 replies if something earns it
- Maybe one post if an hour has passed
- Leave

## Success

Looks like a founder living in the niche all week, not a weekday posting
bot on a metronome.
